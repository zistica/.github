We're **Zistica Inc.**, an independent infrastructure company in **Tokyo, Japan**. We build the
tools we kept wishing existed — the kind that *just work*, run on your own machine, and never
make your data leave it. Two product lines, one principle: infrastructure should be invisible.

### 📊 Data infrastructure

Real-time visibility and control for modern data stacks — starting with BigQuery cost.

| Product | What it does | Status |
|---|---|---|
| **Zistica SparQ** | Real-time BigQuery cost monitoring — see spend as it happens, no surprise bills | 🟢 Live |
| **Zistica Cache** | Query result caching that pays for itself | 🗓️ Q2 2026 |
| **Zistica Sync** | Effortless data sync, zero-config | 🗓️ Q4 2026 |

### 🛡️ AI-agent infrastructure · open source

A local-first **firewall + flight recorder for LLM agents**: a full trace of every model
call, tool, and decision — plus a real-time policy engine that blocks credential exfil,
cross-tenant leaks, and destructive tool calls. One container, no account, no data egress,
**Apache-2.0**. In active development, in the open — watch this org for the release.

### Why teams trust Zistica

- **Local-first by default** — your data and traces stay on your infrastructure. Nothing phones home.
- **Open source where it counts** — Apache-2.0, auditable, no lock-in.
- **Built by operators** — shipped from real production pain, not a pitch deck.
- **Building in public** — roadmap, issues, and progress are out in the open.
